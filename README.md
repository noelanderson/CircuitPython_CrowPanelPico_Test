# CircuitPython_CrowPanelPico_Test
Test code using Circuit Python on an Elecrow CrowPanel Pico Display-4.3 inch 320*240 Touchscreen

An Arduino port of this project is available in [arduino/CrowPanelPico_Arduino](arduino/CrowPanelPico_Arduino), for use with the Arduino IDE and the `arduino-pico` (Earle Philhower) RP2040 board package instead of CircuitPython.
